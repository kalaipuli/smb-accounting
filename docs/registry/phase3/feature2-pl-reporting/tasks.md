# Phase 3 — Feature 2 — P&L Reporting (Period-Type Menu → Period Selector → Report Summary)

Three-page reporting flow reached through the existing main-menu "Reports" route, aggregating
sales/discount/cost data into the eleven-field P&L dataclass (ADR-008 Decision (d)) for the
selected period (daily/monthly/quarterly/annual). Depends on Feature 1 (PHFEAT-01) — consumes the
COGS snapshot for `cogs`/`lines_missing_cost`/`cost_complete`.

**Cites:** PHFEAT-02 — "P&L reporting — daily/monthly/quarterly/annual profit & loss aggregation and
display, sourced from sales (DLVR-2-01) and the per-line cost snapshot delivered by DLVR-3-02.
Reached through DLVR-1-01." (parent DLVR-3-01)

Governing ADR: `docs/adr/ADR-008-pl-reporting-period-semantics.md` — `Status: Accepted` (2026-08-10,
authored and accepted before this task list, `framework/spaces/phase3-start.md` action 3). No
ADR-authoring task appears in this feature's list — the ADR predates this planning run.

UX source: `framework/spaces/phase3-structure.md` § Reference notes, "UX Proposal — Phase 3
Reporting Pages" (ux-designer, action 1, `done`); global style guide `docs/design/style-guide.md`.
